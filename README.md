# Z-Core

Shared design system for all tools. A dark-only retrofuturistic theme providing consistent styling across projects.

## Usage

Link the core stylesheet in any project:

```html
<link rel="stylesheet" href="https://mosermd-bio.github.io/z-core/core.css">
```

Use a local `style.css` only for app-specific overrides.

## Style Guide

View the live style guide at: [https://mosermd-bio.github.io/z-core/](https://mosermd-bio.github.io/z-core/)
